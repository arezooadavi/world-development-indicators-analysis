
# World Development Indicators Analysis

## Overview
This project explores development indicators across countries using data from the World Bank's World Development Indicators (WDI) database.

## Objectives
- Analyze GDP per capita.
- Explore life expectancy at birth.
- Examine secondary school enrollment.
- Analyze unemployment rates.
- Investigate correlations between development indicators.
- Compare selected countries.

## Dataset
**Source:** [World Bank — World Development Indicators](https://datacatalog.worldbank.org/search/dataset/0037712/world-development-indicators)

**Analysis year:** 2020

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Methods
- Data inspection and preparation
- Missing-value analysis
- Descriptive statistics
- Correlation analysis
- Data visualization
- Country comparison

## Project Files
- `WDI_Project.ipynb` — Main notebook containing the analysis.
- `WDI_Development_Analysis.csv` — Analysis output.
- `WDI_Statistics.csv` — Statistical results.

## Limitations
- Some indicators may contain missing values.
- The analysis focuses on 2020.
- Correlation does not necessarily imply causation.
